# 모아 · LMS 학습 플래너

한동대학교 LearningX/Canvas 일정을 한곳에서 확인하는 Flutter UI 프로토타입입니다.

## 실행

```sh
flutter pub get
flutter run
```

IDE에서 이 프로젝트 폴더를 열고 iPhone 시뮬레이터 또는 Android 에뮬레이터를 선택해 실행할 수도 있습니다. iOS 빌드에는 macOS와 Xcode가 필요합니다.

## 화면 흐름

1. **Google 로그인** → 입력이나 실제 인증 없이 버튼을 누르면 다음 화면으로 이동
2. **LMS 토큰 입력** → 빈 값도 허용. 입력한 문자열은 저장·검증·전송하지 않음
3. **홈** → 마감순 목록, 과목/유형 필터, 기한 없는 활동
4. **달력** → 월 이동, 오늘로 복귀, 과목별 일정 점, 선택한 날짜의 활동
5. **활동 상세** → 기한·본문·완료 버튼. 기한 정보는 접어서 표시하고 알림은 상단 아이콘에서 설정
6. **설정** → 기본 알림 시점, 전체 알림, 완료 항목 표시, 토큰 화면, 로그아웃

홈은 필터와 마감순 목록, 달력은 월별 날짜와 선택일의 활동만 표시합니다. 토큰 발급 도움말과 기한 출처는 필요할 때 펼쳐볼 수 있습니다. 데모 동작의 설명은 설정의 앱 정보에 모았습니다.

홈·달력·상세화면은 같은 메모리 상태를 공유합니다. 완료한 활동은 기본적으로 숨겨지며 설정에서 다시 표시할 수 있습니다. AI가 추출한 기한은 별도 확인 없이 일정에 반영되며, 상세화면에서 직접 수정할 수 있습니다.

## 현재 구현 범위

- 실행일을 기준으로 상대 날짜를 생성하는 4개 예시 과목과 10개 활동
- 기한 경과, 오늘·내일 마감, AI 추출, 완료 상태, 기한 없는 자료
- Flutter SDK 위젯과 공식 `url_launcher` 플러그인 사용
- 분석 서버, LMS API 조회, 실제 Google/LMS 인증, 실제 알림 예약 없음
- 강의 상세는 재생시간과 영상 바로가기 중심. 재생시간은 더미 값이며 연결 시 실제 메타데이터로 교체해야 함
- 데이터베이스 예시 강의에는 제공된 실제 URL 연결. 다른 예시 강의는 링크 미연결 상태
- 영상 바로가기는 LMS 원본 HTTPS 주소를 앱으로 열기 시도 후 브라우저로 대체. LearningX의 링크 수신 지원과 기기 설정에 따라 동작이 달라지므로 실기기 확인 필요
- 앱 내부에서 영상을 재생하거나 시청만으로 완료·출석을 처리하지 않음
- 변경한 일정·설정은 메모리에만 유지. 앱 재시작 또는 로그아웃 시 초기화
- 완료 표시는 앱 내 예시 상태이며 실제 제출·출석 정보가 아님

## 구조

- `lib/main.dart`: 앱 시작, 테마 연결, 임시 로그인 흐름
- `lib/models/activity.dart`: 활동/과목 모델, 더미데이터
- `lib/state/demo_store.dart`: 화면이 공유하는 상태와 변경 작업
- `lib/ui/`: 로그인, 토큰 입력, 탭, 홈, 달력, 상세, 설정, 공통 UI
